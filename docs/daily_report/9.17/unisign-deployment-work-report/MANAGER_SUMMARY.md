## 两个问题的答案

1. **Uni-Sign 自己会输出带时间戳的句子分段吗？** 不会。它的 `generate()` 只返回一段解码后的文字，没有时间戳、没有句子边界。现在 API 里看到的 `segments` 字段（start=0，end=整段视频时长）是服务包装层人为拼出来的"伪分段"，不是模型原生能力。
2. **之前跑 benchmark 时，是先切片再跑模型，还是整段跑完再切？** 是先切片。How2Sign v2 用的片段本来就是官方预先切好的句子级片段，Uni-Sign 是对每个片段单独跑一次，不存在"整段长视频跑完再切分"的流程。

## Checkpoint 来源（回答 follow-up）

`how2sign_pose_only_slt.pth` 是此前评测工作自行从 **Hugging Face 官方仓库**（`ZechengLi19/Uni-Sign`）下载的，**不是您发的**，也从未提交进 Git（按设计排除，属于二进制大文件）。文件大小约 1.187GB，sha256 已记录并跨仓库核对一致，许可证 CC BY-NC-4.0（非商用）。

参数量方面：OpenSLT 经重新核对，两个数字其实都对，只是口径不同——checkpoint 里 187 个权重条目原始求和是 11,746,819，但其中 decoder 的输入词嵌入和输出投影层实际上是同一个逻辑参数矩阵被重复存了两份（数值完全一致），去重后的"唯一参数量"是 **9,954,819**，建议对外统一用这个数字。Uni-Sign 约 5.87 亿参数这个数字目前没有在仓库里找到独立审计依据，建议引用前再核实一次来源。
