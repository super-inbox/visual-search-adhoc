# LinkedIn Post — Visual Search Pilot Study (Public v2)

---

We ran a small-scale pilot: **58 queries across 5 visual search platforms**.

The main finding isn't about which platform has more results — all five returned results for most queries. The finding is about *where* on the spectrum from consumption to creation each platform sits, and what that means for users who want to make something.

---

**The 5 platforms, positioned on a spectrum:**

```
Consumption-oriented ◄────────────────────────────► Creation-oriented

  Google Images  /  Bing Images  /  Pinterest  /  Curify  /  Canva
```

Google and Bing anchor the consumption end: broadest recall, no login barriers, richest taxonomy signals. Pinterest sits in the middle: best visual diversity, and the most granular sub-intent signal available in this pilot. Canva and Curify anchor the creation end: results are templates you can generate and adapt, not open-web images you can only view.

---

**3 cross-platform insights worth sharing:**

**1. Bing has the richest query taxonomy signal.**
Average 39.9 related-search label chips per query — 2.2× Google's 17.8. Chips are structured noun-phrase sub-categories, not raw keyword suggestions. The best external source for understanding how a topic branches into sub-topics.

**2. Pinterest sub-intent label chips reveal user-level needs that broad taxonomy misses.**
For `monstera plant care guide infographic`, Pinterest surfaced label chips: Indoor / Swiss cheese / Adansonii / Thai constellation / Moss pole. That's user intent decomposition — which sub-varieties and care methods users are actively filtering by. Bing's taxonomy chips tell you the category space; Pinterest chips tell you what users are actually looking for inside it.

**3. Creation-oriented queries are where platforms diverge most sharply.**
Consumer queries (fan content, travel, lifestyle, nature) are well-served by every platform in this pilot. Creation-oriented queries — educational printables, recipe posters, design templates — show the clearest split: Google and Bing return images to look at, while Canva and Curify return templates to generate from. Canva blocks CJK queries behind a login wall (21/58 queries); Curify has no login barrier.

---

*Small-scale pilot. 58 queries, June 2026. Qualitative + semi-quantitative. Directional findings — not a full benchmark.*
