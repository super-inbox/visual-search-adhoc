## What was actually generated instead — important deviation

**This asset could not be produced as real or photoreal lifestyle photography** — no photography-
capable generation tool was available in this session (see `ASSET_GENERATION_NOTES.md`). What was
built instead is a **flat-illustrated desk scene**: an illustrated laptop silhouette, a simple
SVG potted-sprout illustration, a kraft-toned desk surface, and warm "window light" gradient
lighting, with the Lychee Rose can (via the shared `Can` component) placed on the desk and the
campaign headline ("轻盈气泡，源头养分 / Light bubbles. Real nourishment.") overlaid at top.

This preserves the **structural role** Rule 5 assigns to this touchpoint (the one deliberately
non-product-render, more human/contextual asset in the system) but substitutes illustration for
photography, since photography generation was not available. This is flagged as the single largest
deviation from `ASSET_PLAN.md` across all 5 assets — see `CROSS_ASSET_CHECK.md` §CGI vs lifestyle
usage for the full accounting.
