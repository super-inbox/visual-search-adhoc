## Known acquisition limitations (govern everything downstream)

1. **One image per work**, not the full case study. Each image is that work's cover/hero shot
   (work_09's is its first product shot, since its case opens with a text section). No back-panel,
   construction, color-proof, or multi-SKU-lineup images were acquired.
2. **Screenshot resolution** (1194×650 browser viewport), not the source's native resolution —
   enough to read color families, layout, and type composition, but not exact hex values or
   fine print.
3. **work_10 is partially rendered** — only the left portion of the captured frame carries real
   image content; the right half is blank. Only the tree-shaped bottle-cap and "innovite STEP"
   wordmark are usable evidence from this work.
4. No login was used and none of ZCOOL's "HD original quality" (会员/登录 gated) content was
   accessed — all evidence comes from what an anonymous visitor sees.
5. Because of (1)-(3), every downstream claim in `PERSONAL_DESIGN_SYSTEM.md` is capped at what a
   single cover shot can support: recurring *tendencies* across works, not verified brand-guideline
   facts (no claimed hex codes, no claimed font names, no claimed physical measurements).
