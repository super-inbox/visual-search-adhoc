# Personal System Summary

One-page readout of `PERSONAL_DESIGN_SYSTEM.md`. See that document for full rules and
`PERSONAL_SYSTEM_VALIDATION.md` for the criteria check.

## Top 5 signature rules

1. **One dominant hue + one small accent** — never a flat multicolor palette (5 works: 01, 02, 03,
   06, 07).
2. **One fixed "super-symbol" mark, reused verbatim across every SKU/format in a family** — the
   studio's core stated methodology, directly evidenced (4 works: 01, 05, 06, 09).
3. **Systematic bilingual Chinese + Latin naming**, with the size hierarchy between the two decided
   per brief, not fixed (4 works: 01, 03, 04, 09).
4. **Default to photoreal CGI-rendered mockups with dramatic studio lighting**; real photography is
   a deliberate, occasional exception, not the norm (7-vs-2 works).
5. **Category-conditioned staging**: dark/dramatic backdrops for heritage or premium work, light/
   pastel backdrops for soft-goods, wellness, or children's work (4-vs-4 works).

## Strongest evidence

Rules 1, 2, 3, 5, and the ensemble-composition rule (7 in the full doc) are each backed by 4-7
independent works with directly observed (`[A]`-tagged) support, and none of them lean on work_10
(the one partially-rendered image) at all. Rule 5's CGI-vs-photography split and Rule 1's
color-discipline are the most mechanically checkable of the set — easiest to verify against any
newly generated output.

## Weakest evidence

**Rule 4 (form-as-symbol)** is the softest of the seven HIGH rules: it clears the 3-work bar only
by counting work_10's tree-shaped cap, which comes from a half-blank screenshot. Strip work_10 and
this rule drops to MEDIUM (work_01, 05 only). Treat it as a good idea to try, not a hard
requirement, in Phase 3.

The one MEDIUM rule (sticker-shaped callout tags, work_02 + work_07) is honestly labeled as such —
real but optional, not core to the system.

## Is this portfolio strong enough to proceed to Phase 3 (generation)?

**Yes, with one explicit caveat.** Seven independently well-supported HIGH rules plus one honest
MEDIUM rule is enough decision logic to meaningfully constrain a new brand's color strategy, symbol
strategy, bilingual presence, rendering mode, staging mode, and multi-SKU composition — the system
is specific enough to fail a generated output that ignores it, and broad enough (stated as logic,
not fixed values) to apply to the unseen "荔泉气泡" sparkling-water brief from `DEMO_SPEC.md`. The
caveat: Rule 4 should be applied as optional/aspirational rather than mandatory, given its thinner
evidence base.

## What's still missing because of one-image-per-work sampling

- No back-panel, ingredient-label, or construction/production detail for any work — Phase 3
  generation should not attempt to replicate print-production specifics (bleed, stock, dieline)
  this system was never shown.
- No exact color values or confirmed typefaces for any brand — Phase 3 must describe/generate
  colors and type by family and behavior (as this system does), not by copying a specific hex or
  font from any sampled work, since none were reliably observable.
- No visibility into how any *single* brand's system looks across its full range beyond what one
  cover shot shows (e.g., we don't know work_01's or work_06's back-panel treatment, or whether
  work_09's mascot appears identically on its pouch/tube/card, only that it appears on the box).
- work_10 remains the weakest single data point in the set; if higher-resolution or additional
  images ever become available (e.g., via a user-provided login session), re-validating Rule 4
  specifically would be the highest-value follow-up.
