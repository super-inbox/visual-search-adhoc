9 Do / Don't

Do

  • Keep any single deliverable to 2–3 colors
  • Lean into earth tones/paper-craft texture for regional food-agri briefs
  • Match rendering mode to category, not one default
  • Expect strong technical polish in VI/collateral

Don't

  • Assume a repeated graphic symbol or mascot — none found
  • Assume one fixed color family for the whole studio
  • Assume illustration is the default — more than half the sample is photography or flat graphic design
  • Over-claim the numeral-icon (§4) or ink-brush accent (§6) as stable rules — both single-work

10 Agent Design Guide

For a downstream generation agent

  1. Identify the client category first — this studio's whole approach follows from it, not from a fixed house style.
  2. Keep any single deliverable's palette to 2–3 colors.
  3. For regional food/agriculture briefs, default to earth tones and a paper-craft/kraft surface look.
  4. Choose rendering mode deliberately: photography for food-realism briefs, illustration for fashion-forward premium goods, clean flat graphic design for corporate/VI work.
  5. Do not invent a "signature symbol" for this studio — none was found across 8 sampled works; build the identity from the client's own mark instead.
