## 1. Visual DNA

**Keywords:** regional-agricultural authenticity · restrained per-piece palette · category-driven
register shift · production-ready documentation · Ningxia identity.

**Atmosphere:** a studio whose signature is **competency and range** rather than one repeated
visual mark — rustic, earth-toned realism for regional food/agri clients; a notably more
fashion-editorial illustrative register for a premium wine client; precise, measurement-annotated
technical output for VI/collateral work. [B], cross-checked across all 8 works.

## 2. Color System

- **No single "house" dominant hue** repeats across clients the way it does for 造物起异 — each
  piece's palette is fully client/category-driven: red/white (ul_01, food), blue (ul_02, education/
  camp), red+multicolor feather (ul_03, agri VI), tan+dark-green (ul_05, rice), pink-to-purple
  pastel gradient (ul_06, wine), green (ul_08, wellness). [A]
- **What does repeat: a restrained 2–3-dominant-color discipline within any single piece** —
  ul_02, 03, 05, 07, 08 each read as clearly built from 2–3 colors, not a busy multicolor palette.
  [A], 5 works.
- **Earth tones (tan, khaki, olive-green, brown) recur specifically for the regional food/agri
  client set** (ul_04, 05, 07). [A], 3 works.
- Palette descriptions here are **approximate visual reads from screenshots**, not claimed
  production colors.

## 10. Design Personality

Practical and client-responsive rather than symbol-driven; comfortable across photography,
illustration, and technical documentation; strongest, most confident register is regional
food/agricultural branding with an authentic, unpolished, earth-toned honesty rather than glossy
CGI perfection. [B]

## 11. Do / Don't

**Do:** keep any single deliverable's palette to 2–3 colors; lean into earth tones and paper-craft
texture for regional food/agri work; match rendering mode (photo/illustration/flat-graphic) to the
category rather than defaulting to one; expect strong technical/production polish in VI and
collateral work.

**Don't:** assume a repeated graphic symbol or mascot — none was found across 8 works; assume one
fixed color family speaks for the whole studio; assume illustration is the default (more than half
the sample is photography or flat graphic design); over-claim the numeral-as-icon device (§3) or
the ink-brush accent (§6) as stable rules — both are single-work observations.
