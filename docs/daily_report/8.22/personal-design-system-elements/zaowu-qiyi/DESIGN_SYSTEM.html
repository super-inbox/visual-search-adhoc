9 Do / Don't

Do

  • One dominant hue + one small accent
  • One fixed mark reused everywhere
  • Bilingual naming
  • CGI staging by default
  • Match backdrop to category
  • Ensemble shots for multi-SKU lines

Don't

  • Two dominant colors on one item
  • A unique mark per SKU
  • Assume one language always leads
  • Assume one illustration style fits every brand
  • Assume a border/frame device — none found
  • Invent exact colors/fonts

10 Agent Design Guide

For a downstream generation agent

  1. Choose the register (dark/heritage vs. light/wellness) based on the brief's category — don't default to one.
  2. Pick one dominant hue; add exactly one small accent color.
  3. Design one simplified graphic mark before designing any individual package; reuse it unchanged across every SKU.
  4. Decide bilingual hierarchy (CN-leads vs. near-parity) per brief.
  5. Default to a clean CGI-style render; use real photography only as a deliberate exception.
  6. For multi-SKU briefs, compose a family/ensemble shot, not isolated single-item shots.
