1. **Exact reference available** — a real image of the specific product/template subject.
2. **Adjacent reference available** — a real image of a closely related but not-exact subject, clearly labeled.
3. **Only Curify-gap screenshot available** — we can show the gap, but not what a competitor/reference product looks like.
4. **Competitor source missing entirely** — no exact or adjacent reference found after an expanded repository search.
